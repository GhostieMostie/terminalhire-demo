# slugify-demo

A tiny `slugify(string)` helper that turns arbitrary text into a URL-safe slug.

```js
import { slugify } from './src/slugify.js';
slugify('Hello, World!'); // → 'hello-world'
```

Run the tests:

```bash
npm test
```
